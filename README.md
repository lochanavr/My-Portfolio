# My-Portfolio

### 📌 Personal Portfolio Website

This is my **personal portfolio website** designed and developed using **HTML, CSS, and JavaScript** to showcase my skills, projects, education, and contact information. The website is fully responsive and provides a modern, clean user interface that reflects my personality and professional background.

---

### 🔗 Live Demo
👉 [View Website](https://lochanavr.github.io/My-Portfolio/) 

---

### 📂 Features

- ✨ **Responsive Design** – Mobile-first, fully responsive layout
- 🧠 **About Me** – Brief personal introduction with education and certifications
- 💼 **Skills Section** – Displays frontend, backend, and database expertise
- 🚀 **Projects Section** – Highlights my top projects with GitHub links and live demos
- 📬 **Contact Section** – Easy-to-use contact information for collaboration or hiring
- 🎯 **Interactive Hamburger Menu** – Smooth navigation on mobile devices
- 📄 **Resume Download** – Visitors can directly download my CV

1. Clone the repository:

2. Open `index.html` in your browser or run it using a live server in your code editor.
3. Customize the content (`index.html`, `style.css`, `mediaqueries.css`) with your own information if you’re reusing this as a template.
